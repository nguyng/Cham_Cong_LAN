# 📋 Phần Mềm Chấm Công LAN

Dự án môn **Lập Trình Mạng** — Xây dựng phần mềm chấm công trên mạng LAN.

## 🛠️ Công nghệ
- **Backend**: Spring Boot 3.x + Spring Security + WebSocket
- **Frontend**: React + Vite + Axios
- **Database**: MySQL 8
- **Mạng**: REST API + WebSocket/STOMP trên LAN nội bộ

## 👥 Nhóm
- Member 1 — Backend Lead (Chấm công, JWT, WebSocket, Random Check)
- Member 2 — Backend Dev (Nhân sự, ca làm, nghỉ phép, báo cáo)
- Member 3 — Frontend Lead (Giao diện nhân viên, chấm công)
- Member 4 — Frontend Dev (Dashboard, Admin, báo cáo)
- Member 5 — Database + DevOps (ERD, SQL, Deploy LAN)

## 🚀 Hướng dẫn chạy

### Backend
```bash
cd backend
mvn spring-boot:run
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
